RMS GitHub

See where your RAM really goes.

Activity Monitor and Task Manager show a wall of numbers. RMS shows what is using RAM right now, in plain language, on your own machine: a memory breakdown, your apps, and every process with its details.

Install and start
pipx install git+https://github.com/adminpydev/RMS
rms run

Or uv tool install git+https://github.com/adminpydev/RMS. Python 3.9+, no sudo.

  • Runs only on your machine
  • Nothing stored on disk
  • Open source (Apache-2.0)

Try it on sample data

Example snapshots from a demo machine, not your computer. Browsers cannot read system RAM, so this page never shows your own usage. Install RMS to see yours.
